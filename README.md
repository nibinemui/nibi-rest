# Castelia Online Website

Responsive fan community website inspired by the visual language of Pokémon Black and White.

## Local run
Requires Node.js 20+. Run `npm start` and open http://localhost:3000.

## Railway
Configured for Railway's Node.js buildpack and listens on the Railway-provided PORT.

## Notes
- Original CSS and vector-style city art; no game artwork, ROMs, or proprietary assets are included.
- Update community links, client downloads, announcements, and live server status when their destinations/API exist.
- No live server status is claimed until a status endpoint is configured.
